# Telegram-бот на кшталт Iris

Бот відповідає на питання, коли:
- його тегають (`@ім'я_бота ...`);
- відповідають реплаєм на його повідомлення;
- звертаються по імені в тексті (за замовчуванням: `Ірис`, `Iris`, `бот`, `бота`, `боте`).

Пам'ятає останні повідомлення в кожному чаті (контекст), команда `/reset` очищає пам'ять.

## Встановлення

```bash
pip install -r requirements.txt
```

## Налаштування

1. Скопіюй `.env.example` у `.env`:
   ```bash
   cp .env.example .env
   ```
2. Встав свій `BOT_TOKEN`, отриманий від [@BotFather](https://t.me/BotFather).
3. Встав свій `GEMINI_API_KEY` — безкоштовний ключ береш тут: https://aistudio.google.com/apikey
   (потрібен лише Google-акаунт, без картки).
4. За бажанням зміни `TRIGGER_NAMES` — список слів, на які бот реагує.

### Ліміти безкоштовного тарифу Gemini

Модель `gemini-2.5-flash` за замовчуванням: **10 запитів/хв, 250 запитів/день**,
250 000 токенів/хв. Для невеликого групового чату цього більш ніж достатньо.
Якщо потрібно більше запитів на день — постав `GEMINI_MODEL=gemini-2.5-flash-lite`
(до 1000 запитів/день, трохи слабша якість).

⚠️ Google може використовувати запити й відповіді безкоштовного рівня для
покращення моделей — не відправляй через бота конфіденційні дані.

## Запуск

```bash
python bot.py
```

## Важливо: права бота в групі

Щоб бот бачив усі повідомлення в групі (а не тільки команди й реплаї на себе),
вимкни Privacy Mode:

1. Напиши [@BotFather](https://t.me/BotFather) → `/mybots`
2. Вибери бота → `Bot Settings` → `Group Privacy` → `Turn off`

Без цього бот реагуватиме тільки на явний `@тег` і реплаї, але не на
згадку імені в довільному місці повідомлення.

## Заміна AI-провайдера

За замовчуванням бот використовує безкоштовний Gemini API (`gemini-2.5-flash`).
Якщо захочеш перейти на Anthropic API (Claude) або OpenAI — структура коду
дозволяє це зробити, замінивши блок виклику AI у функції `handle_message`
в `bot.py` на відповідний SDK.

## Розгортання 24/7

Для постійної роботи бота (не тільки поки відкритий термінал) використовуй:
- `systemd`-сервіс на своєму сервері/VPS,
- або Docker-контейнер,
- або хмарні сервіси типу Railway, Render, Fly.io.

Дай знати, якщо потрібен приклад `systemd`-юніта або `Dockerfile`.
